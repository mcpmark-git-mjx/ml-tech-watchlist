# ML Tech Catalog — 7 projects

| Technology | GitHub Repository | Main Functions |
| --- | --- | --- |
| Claude Code | https://github.com/anthropics/claude-code | Anthropic's agentic coding tool that lives in the terminal and IDE: it understands a codebase, edits files, runs shell commands, explains code and handles git workflows from natural-language prompts; the repository ships installers, the TypeScript SDK, plugins and the public issue tracker. |
| FlashAttention | https://github.com/Dao-AILab/flash-attention | Official implementation of FlashAttention and FlashAttention-2 (with FlashAttention-3/4 kernels): IO-aware exact attention plus CUDA/Triton kernels and PyTorch modules that cut GPU memory reads and writes for faster, more memory-efficient Transformer training and inference. |
| Gemini CLI | https://github.com/google-gemini/gemini-cli | Google's open-source (Apache 2.0) terminal AI agent for Gemini: chats about a codebase, reads and edits files, runs shell commands, grounds answers with Google Search and connects external tools through MCP servers. |
| o1 Reasoning | https://github.com/srush/awesome-o1 | Curated bibliography, tutorial slides and learning resources for understanding and reproducing OpenAI o1-style reasoning models, covering chain-of-thought, reinforcement learning, search and test-time compute. |
| OpenAI Codex CLI | https://github.com/openai/codex | OpenAI's open-source terminal coding agent (Rust CLI plus TypeScript SDK) that plans and applies multi-file code changes, runs commands and tests inside sandboxed environments, and supports interactive or headless automation and code review. |
| OpenHands | https://github.com/OpenHands/OpenHands | Open-source autonomous software-engineering agent and self-hosted "Agent Canvas" control center: agents write code, run commands, browse the web and complete development tasks across local, Docker, VM and cloud backends with any LLM. (Formerly published at github.com/All-Hands-AI/OpenHands, which now redirects here.) |
| Qwen3-Coder | https://github.com/QwenLM/Qwen3-Coder | Open-weight, code-focused Qwen3 LLM family (480B-A35B, 30B-A3B, Next): model cards, quick-start code, links to the Hugging Face/ModelScope weights and serving notes for vLLM, SGLang, Ollama and llama.cpp tooling. |
