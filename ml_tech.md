# ML Tech Catalog — 5 projects

| Technology | GitHub Repository | Main Functions |
| --- | --- | --- |
| Claude Code | https://github.com/anthropics/claude-code | Agentic coding tool that lives in the terminal: it reads a codebase, edits files, runs commands and handles git workflows from natural-language prompts; ships with an SDK, plugins and the product's public issue tracker |
| Gemini CLI | https://github.com/google-gemini/gemini-cli | Google's open-source (Apache 2.0) command-line AI agent for Gemini: chats about a codebase, reads and edits files, runs shell commands, grounds answers with Google Search and adds tools through MCP servers |
| OpenAI Codex CLI | https://github.com/openai/codex | OpenAI's open-source terminal coding agent (Rust CLI plus TypeScript SDK) that plans and applies multi-file code changes and runs commands and tests inside a sandboxed environment |
| OpenHands | https://github.com/OpenHands/OpenHands | Open-source autonomous software-engineering agent plus the self-hosted "Agent Canvas" control center that runs coding agents and automations across local, Docker, VM and cloud backends with any LLM (project formerly published as All-Hands-AI/OpenHands) |
| Qwen3-Coder | https://github.com/QwenLM/Qwen3-Coder | Open-weight, code-focused LLM family from the Qwen team (480B-A35B, 30B-A3B, Next): model cards, transformers quick-start code, links to the Hugging Face/ModelScope weights and notes for serving it with the SGLang/vLLM tool parsers |
